A prediction market is a claim about the future.
This asks what will decide it — and whether anyone can check that.

The settlement path is GraduateMarketUsdc → SubmitOracleResultUsdc → ResolveEventUsdc → ClaimWinUsdc. This tool reads the market account's own history and reports who signed the middle two, because the catalogue's oracle field is a claim about who decides and not the account that does: on every market checked it names the wallet whose instruction is CreateEventUsdc.

What the creator wrote, and what the buyer gets

Panta's create API requires a question, a resolutionRule of up to 2048 characters, and a non-empty sourcesOfTruth. The read API returns none of them under those names. oracle is sourcesOfTruth joined by commas — which is why the most common settlement source in the catalogue is the word on-chain, typed into that list by a creator. resolutionRule is in no read response at all.
